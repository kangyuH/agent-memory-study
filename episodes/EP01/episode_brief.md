# EP01 研究范围｜从任务型对话到 LLM：机器为什么总是忘记？

- 大纲定位：主题 I，`01_Agent_Memory_内容主线.md` 第 35–41 行；无显式前置期。相邻议题为 EP02。
- 信息截止日：2026-11-09。按来源实际首发与采用版本判断是否入界。

## 本期议题

考察订票、查询、客服等有界任务如何定义用户目标、槽位、意图和动作，以及这些结构为何能支持多轮任务。将“忘记”拆成几个可分别取证的失败：信息没进状态、跟踪或更新出错、已存信息未进入下游决策、跨会话未延续。调查任务扩大到新领域、未见值、隐含偏好和复杂经历时，这些失败是否来自不同约束。

## 术语、机制与版本

- 对齐 Slot Filling、意图识别、Dialogue State Tracking、对话策略、POMDP belief state、用户画像、规则存储、RNN/LSTM 隐状态与显式外部状态。分别记录数据表示、可见性、更新时点、使用者与生命周期。
- 用早期有界系统、统计 DST/POMDP、神经跟踪和较晚的跨域或 LLM 跟踪选取可查证的里程碑。追踪论文、数据集版本和实现版本，保留并行路线。
- 核查显式状态支持高效及可控流程的条件，以及新域、新槽、未见槽值、时间条件和偏好例外分别对 Schema 和跟踪机制提出的要求。保留结构化或混合路线有效的反例和可比基线。
- 把模型能否发现值得保留的状态信息列为开放问题，区分在既有 Schema 中提取值、引入新状态类别、自主决定哪些信息值得跨会话保存及实测其后续价值。
