## 2. 显式更新的三种实现

**DSTC2 focus。** 对单个槽和候选值 v，把本轮 SLU 为 v 提供的概率质量写作 e_t(v)。S19 §5.1 规定 p_t(v) = q_t p_(t−1)(v) + e_t(v)，其中 q_t 为 1 减该组件在本轮的证据总质量，首轮 p_1(v) = e_1(v)。SLU 列表已归一，因此旧项系数介于 0 与 1。无新证据时维持旧分布，证据量为 1 时仅取新分布；请求字段可在系统告知时重置。S03 §3.2 将 q_t 刊载为证据和。实际代码未在本次读取。低置信候选、上游误识别与真实更改应分别留痕。[C04] [C05]

**SGD 基线。** 槽状态分支为 none、dontcare、active。槽状态 none 不改变旧值；dontcare 写入无偏好；active 对类别型槽在服务提供的候选中选值，对非类别型槽采用文本位置模型。活跃意图的 NONE 是另一个分类任务，请求槽和用户目标更新也有各自的预测部分。服务 Schema 和文本取值分开。[C06] [C21]

**Diable。** 按域与槽保存表，模型输出差分文本，解释器将操作写到上一轮预测表。论文实现以 INSERT 新建或覆盖已有值，以 DELETE 删除，用字面量 none 表示整轮无操作。这里的 none 属于操作语法；其他实现中的 none 可能是某槽的未给定值。输入可以含前状态或更长历史，输出差分与输入上下文长度独立。预测状态递推可携带错误，提供金标前状态的实验用于估计这类误差的影响。[C07] [C18]

## 3. POMDP 变量和控制流

按 S04 Eq. (2)，设 s 为旧潜在状态，s' 为动作后的状态，a 为系统动作，o 为新观测，b 为旧信念。

```text
predict(s') = sum_s P(s' | s, a) * b(s)
weight(s')  = P(o | s', a) * predict(s')
b_new(s')   = weight(s') / sum_x weight(x)
action      = policy(b_new)
```

这是原公式按计算顺序的复原，需有可归一化的分母。策略的训练或规划使用原文设定的回报，运行时以更新后的信念选择动作。观测可能是受噪声影响的语义结果，转移可以依系统问法和任务。置信不足时澄清是候选动作之一，是否划算由误操作风险和额外交互代价共同决定。S04 §2.1 的语音信箱示例只含 ask、doSave 和 doDelete；§4.1 的旅行仿真另含 confirm。§2.2 将用户目标、用户动作和对话历史等因子分解。§4.5（Fig. 23 附近）的 Summary POMDP 保留其设定下的信念监控，并在摘要空间规划。[C08] [C09] [C10]

失效检查包括目标空间漏项、观测似然失配、候选过大、真实代价改变和策略近似误差。不能由一次正确后验直接断定交易成功。论文中示例、仿真与真实部署条件应分别阅读。

## 5. 隐状态、显式状态和混合结构

| 机制 | 递推输入与输出 | 可检查性 | 重置与失败 |
| --- | --- | --- | --- |
| 原始 LSTM | 输入经门控与内部单元状态参与下一次计算 | 内部数值可观测时仍需要额外方法解释语义 | 初始状态与序列边界由实现定义，原文长依赖属于学习实验 |
| 带遗忘门的 LSTM | 遗忘门对旧单元状态施加可学习的衰减 | 数值门控本身没有用户字段语义 | 可在连续输入中调节或重置内部记忆 |
| 词级 RNN DST | 当前词/动作特征、旧显式概率 p 和内部向量 m，输出新概率 p' 和新向量 m' | 槽分布可检查，内部向量保持数值形式 | 保持同一网络和下一输入时，两类前状态影响续算 |
| 外部表差分 DST | 当前话语和先前表，输出操作并应用 | 可检查具体域、槽和写入操作 | 旧表错误可传播，重置和纠正依协议 |

S08 §3.3 将有标记和无标记的分支输出合成槽候选 logits，再加 None 候选做 softmax。内部向量使用当前特征和旧向量做 logistic 更新。不能把 S08 的内部向量误称为 LSTM 的单元状态。原文词级模型保留外部概率接口。[C13] [C14] [C15] [C07]
