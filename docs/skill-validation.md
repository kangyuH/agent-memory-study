#### 修订与限制

- EP01 修正对词级 RNN 状态跟踪的表述，区分上轮的显式分布和隐向量。AAAI 直链在部分访问路径受限，终审经索引读取会议版，重放时验收报告改用已实测的备用链接。[作者预印本 PDF](https://arxiv.org/pdf/1909.05855)
- EP08 区分 OSTEP 整书版本日期与章节首发日期，也注明文档问答对照中的任务提示差异。终审保留一项账本措辞的轻微改进点，研究稿与资料稿已准确区分模型可读的上下文与经工具写入的内容。
- EP29 首轮母稿和资料包审查分别得到 90 和 91 分，因硬性问题均未通过。母稿补入 FactConsolidation 金标与最后写入规则之间的独立复核，资料稿明确答案评分的可观察边界。修订后两轮审核关闭全部六项问题。复核包括原文和附录样例，未重跑全量基准。[独立复核论文](https://arxiv.org/abs/2610.09193)
- 三期使用紧凑试跑稿，NotebookLM 主输入篇幅低于任务书的软目标。验收终点为资料包导出。EP19 和 EP36 的验证覆盖解析与计划。
