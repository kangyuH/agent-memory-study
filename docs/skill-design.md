# Agent Memory 研究 Skill 设计

以 `reference/01_Agent_Memory_内容主线.md` 作为课程范围的权威输入，以设计任务书约束交付和验收。Skill 放在仓库的 `.agents/skills/agent-memory-research/`，遵循 [Codex Skills 规范](https://learn.chatgpt.com/docs/build-skills)。入口、阶段规范、模板与确定性脚本分开维护。

## 职责与运行方式

| 部分 | 职责 |
| --- | --- |
| Codex 研究者 | 从分期与前置约束建立问题树，打开并核验一手材料，复原技术机制、比较证据、写作及定点修订。 |
| 独立审核者 | 重新打开原始资料，按主张复核证据和范围。审核母稿与审核最终包是两次独立检查。使用独立上下文，写作者不代签。 |
| Python CLI | 解析课程索引，排序依赖，验证结构与引用，保存输入版本、阶段产物、审核和历史，控制恢复与发布。 |
| 外部能力 | 需要能读原文的搜索或浏览工具、独立审查环境和可写输出目录。Python 脚本不请求网络。NotebookLM 接收已验收资料包。 |

使用 `plan` 产出范围和研究计划，`research` 默认运行单期至验收，`review` 只处理当前审核阶段，`resume` 从有效检查点恢复，`release` 导出已验收包，`batch` 按依赖执行。显式参数包括大纲路径、期数或主题、信息截止日、深度、输出目录、强制来源刷新、有界修订次数和审核档位。运行记录保留这些输入及 Skill 内容哈希。

## 状态与数据

`UNPLANNED → BRIEF_READY → PLAN_READY → SOURCES_VERIFIED → EVIDENCE_BUILT → RESEARCH_DRAFTED → RESEARCH_REVIEWED → PODCAST_DRAFTED → FINAL_REVIEWED → ACCEPTED`

阶段写入采用独立收件目录和不可变快照。清单记录阶段、输入、产物的 SHA-256、审核身份和事件。输入或 Skill 版本变化建立新运行。来源刷新保留研究计划并使取证及下游失效。上游更正后回到仍有效的阶段，失效稿件及其审核。中断、缺失资料和质量失败分别记录，可复用仍有效的产物。连续运行采用文件锁与原子清单写入。

大纲解析器支持 `##` 主题下的 `### EPnn｜标题` 及同类中英文标题，读取显式章节依赖。范围检查包含相邻期和直接前置期的定位。批量运行将未验收的显式前置期放在后续期之前。关键术语、时间线与主张可以写入结构化登记表供后续比对，冲突须由研究者和审核者裁决。

## 验收

- 每条关键事实要有可定位的一手证据，推断明确标识。来源身份、版本、时间语义、核心机制、实验条件与负面证据由独立审核确认。
- 按六维评分卡审查。硬性门槛独立于分数，存在未解决的阻塞项、未处理的重大问题、缺失产物或审核快照错配时一律拒绝发布。
- 最终包包括母稿、NotebookLM 资料稿、一手来源表、主张证据矩阵、两次审核与验收报告。保留产物和版本清单以便复审。
- 用 EP01 先验证历史概念型流程，再用 EP08 和 EP29 检查系统架构与评测比较场景。用合成反例检查伪造引用、不可用原文、跨期冲突、注入、断点恢复、重复运行与替代大纲。合成测试结果和真实内容验收分别记录。
