# Agent Memory 研究 Skill 设计

以 [课程主线](../reference/01_Agent_Memory_内容主线.md) 定位议题与范围，以 [调研职责修订](../reference/03_调研职责边界与资料交付修订.md) 规定现行交付与验收。原任务书记录历史设计。Skill 位于 `.agents/skills/agent-memory-research/`，遵循 [Codex Skills 规范](https://learn.chatgpt.com/docs/build-skills)。

## 职责

| 部分 | 职责 |
| --- | --- |
| 调研者 | 设计可调查的问题，打开并核验一手材料，归纳技术机制、证据、概念与限制。 |
| 独立审核者 | 重开原文，查找问题设计与材料覆盖缺漏，核实结论、版本和适用条件。第二次审核复核最终交付与修订闭合。 |
| Python CLI | 解析课程索引，排序显式依赖，校验覆盖关系和快照，控制恢复与导出。 |
| 下游使用者或 NotebookLM | 取用资料后决定呈现顺序、解释方式、例子与篇章衔接。 |

使用 `plan` 产出范围和问题清单，`research` 默认运行单期至验收，`review` 处理当前审核阶段，`resume` 从有效检查点恢复，`release` 导出已验收包，`batch` 按证据依赖执行。环境需要可读原文的工具、独立审查和可写目录。确定性脚本只访问本地材料。

## 状态与数据

`UNPLANNED → BRIEF_READY → PLAN_READY → SOURCES_VERIFIED → EVIDENCE_BUILT → MATERIALS_DRAFTED → MATERIALS_REVIEWED → FINAL_REVIEWED → ACCEPTED`

阶段写入采用独立收件目录和不可变快照。清单记录输入、版本、产物哈希、审核身份和事件。来源刷新复用有效的问题计划。必要问题变化时回退重定清单，重新核验受影响的来源和下游材料。原子写入和文件锁保护状态。

`research_questions.json` 为问题提供稳定编号和必要性依据。账本中的 `question_ids` 对应这些编号，`coverage.json` 记录每个问题的状态和全部相关主张。主文档 `research.md` 保留问题、主张、反证、条件与缺口。批量以当前版本的验收判断前置期，历史资料可单独查询和导出。

## 验收

- 核验来源身份、版本、时间和原文定位。审查重点覆盖定义、机制、实证、反例、条件与未知项。
- 独立审核逐题检查范围和证据是否足以支持归纳。必要问题缺口、阻塞项、证据映射遗漏或审核快照错配阻塞验收。非必要缺口随包归档。
- 导出研究汇总、参考文献、证据矩阵、概念登记、覆盖表、两轮审核、验收报告与版本清单。
- 用合成反例检查漏题、漏主张、虚标覆盖、关键来源缺失、跨期冲突、断点恢复、重复运行和替代大纲。真实资料验证另列范围和结论。
