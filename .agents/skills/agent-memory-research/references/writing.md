# 研究资料归纳与问题覆盖

以问题或来源为目录。用 `[Qnn]` 标注全部研究问题，用 `[Cnn]` 关联账本中每条主张。每个问题汇总直接证据、来源冲突、可支持的结论、适用条件、反例和已知缺口。技术笔记归档可复查的机制细节、原文案例和实验表。复原步骤或推断时写明所依据的原文和假设。

涉及比较时保留版本、数据集、模型、预算、基线、指标、数值、显著性报告情况和局限。原文未公开的事项明确记为未披露。若问题是“论文是否报告某指标”，逐段核对原文后可以用有出处的未报告发现回答。若问题是“效果是否存在”，缺少可用结果时记录证据缺口。

## 覆盖状态

| 状态 | 含义 |
| --- | --- |
| `covered` | 相关的一手事实、作者陈述或实验结果已能回答该问题。记录结论及适用边界，`gaps` 为空列表。 |
| `partial` | 已有一手证据支持部分内容，仍有关键方面待补证。 |
| `unresolved` | 现有材料不足以回答。保留相关背景与缺口。 |

为每个计划问题创建一条 `coverage.json` 记录。`claim_ids` 必须完整映射账本中指向该问题的主张。`detail` 简述覆盖范围，`gaps` 列出尚缺的材料、检索过的途径和影响。必要问题的 `partial` 或 `unresolved` 状态阻塞验收。开放探索项可带着显式缺口归档。

`research.md` 是交付的主要研究文档。附完整的 `references.md`、`evidence_matrix.md`、`technical_notes.md` 与概念登记。核验所有提供给使用者的入口链接。出版社限制直开时，附上已打开的备用原文并注明版本差异。材料可交给 NotebookLM 自行组织解释。
