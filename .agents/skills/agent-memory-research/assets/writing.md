# 成稿模板

## research.md

1. 主问题、失败现场和范围。
2. 历史条件及当时可行的基线。
3. 各路线的机制、流程、假设和限制。
4. 一手证据、对照条件、反例及取舍。
5. 继承与演变、剩余问题与下一期衔接。
6. 结论及 `[Cnn]` 追溯。

## podcast_source.md

1. 一个贯穿案例、当时的约束和主问题。
2. 子问题和机制，保留母稿中的小型例子。
3. 路线竞争与成立条件，附 `[Cnn]`。
4. 易混术语、失败场景及下一期开放问题。

## 审核与验收报告

- 本次审核的角色、阶段和稿件快照
- 已复核核心主张及其他抽查项目
- 硬门槛、分值、问题清单与复查结果
- 通过、修订或阻塞结论
