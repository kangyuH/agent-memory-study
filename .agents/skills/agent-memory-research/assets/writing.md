# 研究材料模板

## research.md

- 研究议题、材料范围、信息截止日与所用版本。
- 问题索引，用 `[Qnn]` 定位全部问题。
- 按问题归纳事实、作者结论、实验发现、研究推断和开放问题，使用 `[Cnn]` 关联全部主张。
- 保留数据、对照条件、可比较的维度、反例、限制和未披露项。
- 索引参考文献、证据矩阵、概念登记和技术笔记。

## coverage.json

对象列表。每个 `question_id` 恰好对应一条记录，含 `status`、`claim_ids`、`detail`、`gaps`。参照 [资料规范](../references/writing.md) 记录证据覆盖和缺口。

## 审核与验收报告

- 审核阶段、角色与资料快照。
- 逐题核对的来源、事实、版本、条件与覆盖。
- 修订记录、尚未解决的非必要缺口、结论与交付索引。
