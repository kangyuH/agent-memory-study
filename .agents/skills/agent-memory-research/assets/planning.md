# 规划模板

## episode_brief.md

- 期数与主问题
- 历史现场、约束和当前问题边界
- 应讲内容、仅铺垫内容和留给后续期的内容
- 前置概念、对应期数与验收状态
- 本期路线、待核验证据和下期衔接

`scope_contract.json` 使用 `episode`、`include`、`preview_only`、`exclude`、`prerequisites`。后四项为字符串列表，前置期编号按 `scope_input.json` 顺序填写。

## research_plan.md

- 3–4 个可核验的子问题
- 当时的任务、模型和工程条件
- 候选路线、待复原机制及比较条件
- 待检验主张、初步的一手来源与反证查询
- 充分证据的标准和资料不足时的阻塞条件
